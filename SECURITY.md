# Security Policy

## Supported version

Security updates are applied to the latest revision of the `main` branch.

## Reporting a vulnerability

Please report vulnerabilities privately through the repository's GitHub
Security tab instead of opening a public issue. Include:

- the affected component;
- steps to reproduce the issue;
- the expected and observed behavior; and
- any suggested mitigation.

Do not include real credentials, private data, or sensitive production content
in a report.

## Scope

Guardrails Lab is an educational demonstration. Its keyword and regular
expression checks are not a complete security boundary. Applications derived
from this repository must enforce authentication, authorization, data access,
rate limits, and audit controls independently.
